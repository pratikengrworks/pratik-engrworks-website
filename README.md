# Pratik Engineering Works — Website Starter

A responsive, professional one-page B2B manufacturing website built from the supplied company brochure and product imagery.

## Included
- Responsive navigation and mobile menu
- Hero section with industrial imagery
- Company overview
- Rail Clamp and Cable Trolley product sections
- Product configuration/specification tables
- Applications and value proposition sections
- Selected customers section using brochure logos
- Product enquiry form
- Phone, email and WhatsApp CTAs
- Basic SEO metadata

## Enquiry form
The form currently posts to FormSubmit using `pratik.engrworks@gmail.com`.
Before production launch, test the form once, complete any FormSubmit email verification, and change `_next` in `index.html` from `https://example.com/thank-you.html` to your actual thank-you page.

## Important content note
The website uses the customer/product specifications shown in the brochure. Verify all technical values, legal company name spelling, address, phone, email and customer-logo usage before publishing.

## Run locally
Use any static server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
